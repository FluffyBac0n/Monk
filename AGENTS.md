# Workspace instructions

- When launching the Flutter app on any simulator or device, run it from `mobile/` and always pass `--dart-define-from-file=env.local.json` so the Mapbox access token is available.
- Never print, copy, or commit the contents of `mobile/env.local.json`.

# Website design instructions

- Prioritize a modern, minimalistic, functional website with an excellent user experience. Save space and remove redundant information, repeated labels, and unnecessary explanatory copy. Keep the interface concise and avoid chatty text. Use compact layouts where practical while preserving readability, accessibility, clear actions, and functionality.
- Every added or changed website UI element must match EuroTrex's existing look and feel. Reuse the established typography, yellow section-heading rule, sand canvas, button variants, controls and spacing.
- Follow the relevant `-Text` sheets in `Website Design - v3 - Added Host Portal.xlsx`; use existing-site screenshots as visual guides. Keep text concise and do not add unnecessary explanatory copy. Use database figures rather than mock statistics.
